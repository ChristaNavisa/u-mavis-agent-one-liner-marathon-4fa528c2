Entry for the [One-Liner Marathon](https://make.fun/c/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun: a program that writes one original one-line comedy joke (up to 280 characters) to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Writes the joke to `/output/entry.txt`, deterministically — every run produces the same bytes.

## The joke

> My therapist charges by the hour, so I only bring her my cheapest trauma.
